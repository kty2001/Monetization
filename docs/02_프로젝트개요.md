# 프로젝트 개요

## 문제 정의

'문피아'에 무료로 공개 연재 중인 작품을 유료(유료 회차/독점 연재 등)로 전환했을 때, 매출이 어떻게 변화할지 예측한다.

## 참고 프로젝트에서 얻은 인사이트

[SKN34-2nd-3Team](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN34-2nd-3Team) 프로젝트는 유사한 문제(유료 전환 추천)를 다뤘고, 다음과 같은 시사점을 남겼다.

- 단일 시점에 수집한 스냅샷 데이터만으로는 안정적인 지도/비지도 학습 기반 분류가 어려웠다.
- 대신 조회수 규모, 무료/유료 회차별 이탈(잔존)률, 댓글 감성 분석 등을 결합한 **복합 스코어링 방식**이 더 유효했다.
- 데이터의 시계열성 부족이 모델링의 주요 제약이었다.

## 이 프로젝트의 방향 (초안)

- **목표 차별화**: 전환 후보를 추천하는 스코어링이 아니라, 전환 시 **예상 매출액**을 직접 예측하는 회귀 문제로 접근
- **인프라 차별화**: DB(MySQL) 없이 CSV 기반 파이프라인, `uv`로 패키지 관리
- **모델링 순서**: ML(회귀) 모델을 먼저 시도하고, 성능이 부족하다고 판단될 경우에만 DL 도입 검토
- 참고 프로젝트의 교훈을 반영해, 가능하면 여러 시점의 데이터를 수집해 시계열 특성(조회수 추이, 이탈률 추이)을 확보하는 것을 우선 고려

## 향후 계획

1. 문피아 크롤러 구현 → `data/raw/`에 CSV 적재
2. 데이터 정제 및 피처 엔지니어링 → `data/processed/`
3. 매출 예측 모델 실험 (`research/`) 및 학습 스크립트 정리 (`scripts/`)
4. 예측 결과 확인용 대시보드 (`pages/`)
5. 모델 검증 및 개선
