# 프로젝트 개요

## 문제 정의

'문피아'에 무료로 공개 연재 중인 작품을 유료(유료 회차/독점 연재 등)로 전환했을 때, 매출이 어떻게 변화할지 예측함.

매출은 두 조각으로 나눠 다룸.

```
회차당 예상 매출(KRW) = 회차당 예측 구매수 × 회차 단가
                         └ 모델 예측          └ 사용자 입력
```

회차 단가는 작가별 계약에 따라 달라 크롤로 확보할 수 없음. 따라서 **모델은 회차당 구매수만 회귀로 예측하고, 단가는 앱에서 입력받아 단순 곱셈으로 환산**함. 단가는 학습·피처에 개입하지 않으며, 상수배이므로 작품 간 순위에도 영향이 없음. 상세는 [로드맵](04_로드맵.md)의 핵심 결정 사항 참고.

## 참고 프로젝트에서 얻은 인사이트

[SKN34-2nd-3Team](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN34-2nd-3Team) 프로젝트는 유사한 문제(유료 전환 추천)를 다뤘고 다음과 같은 시사점을 남김.

- 단일 시점에 수집한 스냅샷 데이터만으로는 안정적인 지도/비지도 학습 기반 분류가 어려웠음
- 대신 조회수 규모, 무료/유료 회차별 이탈(잔존)률, 댓글 감성 분석 등을 결합한 **복합 스코어링 방식**이 더 유효했음
- 데이터의 시계열성 부족이 모델링의 주요 제약이었음

## 이 프로젝트의 방향

- **목표 차별화**: 전환 후보를 추천하는 스코어링이 아니라, 전환 시 **예상 구매수**를 직접 예측하는 회귀 문제로 접근(매출은 단가를 곱해 환산)
- **인프라 차별화**: DB(MySQL) 없이 CSV 기반 파이프라인, `uv`로 패키지 관리
- **모델링 순서**: ML(회귀) 모델을 먼저 시도하고, 성능이 부족할 때만 DL 도입 검토 → **DL 불필요로 판정**됨. `HistGradientBoostingRegressor`가 단일회귀 베이스라인을 19.7% 개선했고 그 폭이 CV 표준편차의 10배가 넘어 노이즈로 설명되지 않음([모델 명세](06_모델.md))
- **시계열 특성 확보**: 참고 프로젝트의 교훈을 반영해 여러 시점의 데이터 수집을 시도함
  - **현황**: 무료작 스냅샷 2시점을 확보했으나 **현재 모델의 피처로는 쓸 수 없음** — 학습셋은 1회 크롤이고 무료 연재기가 이미 지나 추이를 소급할 방법이 없기 때문임. 스냅샷의 실제 용도는 전향적(prospective) 학습셋의 씨앗이며, 이후 **월 1회 / 목록 앞 200페이지**로 운영함([크롤러](03_크롤러.md) "정기 스냅샷 운영")
