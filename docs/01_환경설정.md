# 환경설정

- Python : 3.13 이상 (`pyproject.toml`의 `requires-python` 기준)
- 패키지 관리 : [uv](https://docs.astral.sh/uv/)
- DB : 사용하지 않음 — 모든 데이터를 `data/` 아래 CSV 파일로 관리

클론부터 앱 빌드까지의 실행 순서는 [실행 가이드](07_실행가이드.md) 참고. 이 문서는 개발 환경 자체만 다룸.

## uv 설치

설치되어 있지 않다면 [공식 설치 가이드](https://docs.astral.sh/uv/getting-started/installation/) 참고.

```bash
uv --version
```

## 의존성 설치

리포지토리 루트에서 실행함.

```bash
uv sync
```

`pyproject.toml`/`uv.lock`에 고정된 패키지가 `.venv`에 설치됨. 개발용 그룹(`pytest`, `jupyter`, `pyinstaller`)도 함께 설치됨.

## 패키지 추가/삭제

```bash
uv add <package>              # 런타임 의존성 추가
uv add --dev <package>        # 개발 의존성 추가
uv remove <package>           # 의존성 제거
```

## 스크립트 실행

가상환경을 직접 activate할 필요 없이 `uv run`으로 실행함.

```bash
uv run python scripts/crawl_munpia.py --max-pages 1 --novel-limit 5
uv run pytest
uv run jupyter lab            # research/ 노트북
```

## 환경변수

크롤러 설정(User-Agent·요청 지연·재시도·타임아웃)은 `.env`로 조정함. `.env.example`을 복사해 필요한 값만 채우며, 비워두면 `clawler/config.py`의 기본값이 쓰이므로 생략 가능함.

```bash
cp .env.example .env
```

## 데이터

DB 대신 CSV를 사용함. 두 디렉토리 모두 `.gitignore` 대상이라 **클론 직후에는 비어 있음**.

- 크롤링 원본: `data/raw/`
- 가공 데이터·모델·예측: `data/processed/`

크롤러 실행 방법과 옵션은 [크롤러](03_크롤러.md), 파일별 컬럼 정의는 [데이터 사전](05_데이터사전.md) 참고.
