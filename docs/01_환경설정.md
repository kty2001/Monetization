# 환경설정

- Python : 3.13 (pyproject.toml `requires-python` 기준)
- 패키지 관리 : [uv](https://docs.astral.sh/uv/)
- DB : 사용하지 않음 — 모든 데이터는 `data/` 폴더 아래 CSV 파일로 관리

## uv 설치

아직 설치되어 있지 않다면 [공식 설치 가이드](https://docs.astral.sh/uv/getting-started/installation/) 참고.

```bash
uv --version
```

## 의존성 설치

리포지토리 루트에서:

```bash
uv sync
```

`pyproject.toml` / `uv.lock`에 명시된 패키지가 `.venv`에 설치된다.

## 패키지 추가/삭제

```bash
uv add <package>       # 의존성 추가
uv remove <package>    # 의존성 제거
```

## 스크립트/앱 실행

가상환경을 직접 activate할 필요 없이 `uv run`으로 실행한다.

```bash
uv run python scripts/some_script.py
uv run streamlit run pages/some_page.py
```

## 데이터

DB 대신 CSV를 사용한다.

- 크롤링 원본: `data/raw/`
- 가공된 데이터: `data/processed/`

크롤러 실행 방법과 옵션은 [크롤러](03_크롤러.md) 참고.
